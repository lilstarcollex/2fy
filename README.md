# 2FA Manager

Лёгкое настольное приложение для TOTP-кодов на Windows. Интерфейс использует shadcn/ui, генерация кодов и работа с хранилищем выполняются локально.

## Использование

- Подтвердите запуск через Windows Hello. После этого повторная проверка понадобится через час.
- Вставьте Base32-секрет в «Быстрый код», чтобы получить разовый код без сохранения.
- Чтобы оставить ключ в приложении, нажмите «Добавить аккаунт», укажите название и секрет. Сохранённые коды копируются одной кнопкой.

Секреты лежат в файле хранилища приложения, зашифрованном Windows DPAPI для текущей учётной записи. Приложение не подключается к сетевым сервисам.

## Разработка и сборка

Нужны Node.js, Rust, Microsoft C++ Build Tools и WebView2 Runtime.

```powershell
npm install
npm run tauri dev
npm run tauri build
```

Сборка Windows создаёт установщики в `src-tauri/target/release/bundle/`.
